# 看山冰淇淋小屋

一个可直接在浏览器中游玩的冰淇淋制作小游戏，已发布于知乎 APP。

## 在线游玩

部署完成后，可通过 GitHub Pages 访问：

`https://irishao-netizen.github.io/game-KANSHANicecream/`

## 本地预览

保持 `index.html`、`game.js` 与 `assets/` 文件夹处于同一目录，直接用浏览器打开 `index.html` 即可。

## 项目结构

- `index.html`：页面结构与样式
- `game.js`：游戏交互逻辑
- `assets/`：图片与音频素材
- `build-standalone.js`：生成离线单文件试玩版的脚本
